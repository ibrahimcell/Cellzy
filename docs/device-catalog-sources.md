# Phone directory source notes

Reviewed 2026-09-12. These sources inform factual device names and search aliases only. A directory entry supports an inquiry; it does not promise stock, parts, a repair price, a warranty, or turnaround for that model. Existing phones and the unlisted-device inquiry remain available.

[Motorola's Moto Z support selector](https://en-us.support.motorola.com/app/standalone/country-selector/motoz/) also identifies Z2 Play, Z2 Force, and Z3 Play.

Used the manufacturer's **ThinQ** spelling, not the competitor's “ThinkQ”: [LG G8S ThinQ](https://www.lg.com/uk/mobile-phones/smartphones/lmg810eaw/) and [LG G8X ThinQ specification sheet](https://www.lg.com/us/support/products/documents/LG_G8X_ThinQ_LMG850UM_Generic_Specsheet_1025.pdf).
- [UniverCell Apple phone selector](https://univercell.ai/repair/mobile/apple): all listed iPhones already existed. Added SE 1/2/3 and generation-name search aliases. [Apple SE comparison](https://www.apple.com/iphone/compare/?modelList=iphone-se-2nd-gen%2Ciphone-6s%2Ciphone-se-3rd-gen) and [Apple SE 3 support](https://support.apple.com/en-gb/docs/iphone/300865) support the 2020/2022 generation aliases.
- [UniverCell Google phone selector](https://univercell.ai/repair/mobile/google): listed Pixels already existed; added “Pixel 5a 5G” as an alias of Pixel 5a, not a second phone.
- [UniverCell OnePlus phone selector](https://univercell.ai/repair/mobile/one-plus): returned no model entries during this review. No names were inferred from that empty selector.

## Deliberately not imported

- No competitor copy, photos, reviews, prices, locations, certifications, warranty promises, financing, or service claims.
- No extra tablet, laptop, watch, console, or other non-phone services.
- No generic duplicate entries for A42/A73 when Cellzy already has their 5G names.
- No new A16 4G/5G split: the existing generic A16 entry remains pending a verified regional model-number distinction.
- No ambiguous A5/A8 generations, A90 shorthand, “A13S”, or A12 Nacho additions without a separate manufacturer/variant check.
- No fabricated model numbers, new-release names, or guessed specifications. Existing Canadian Samsung model-code aliases are retained.
