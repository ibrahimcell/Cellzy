# Cellzy launch checklist

## Business details

- Store address
- Public phone number
- Opening hours and holiday-hour policy
- Confirm whether public email should be `info@cellzy.com` or a `cellzy.ca` address

## Repairs

- Price table by phone model, repair, and screen grade (LCD, OLED, Original)
- Warranty length and exclusions
- Exact list of repairs that are normally completed in 30 minutes
- Appointment capacity per time slot and unavailable dates

## Devices and accessories

- Launch inventory or the system used to manage inventory
- New, used, and refurbished device policy
- Reservation hold time
- Brands and accessory lines to feature first

## Booking delivery

- Verified Resend account and `RESEND_API_KEY`
- Verified sender address for `BOOKINGS_FROM_EMAIL`
- Optional calendar destination if bookings should also create calendar events

## Publishing

- GitHub repository URL
- Vercel project/team name
- Vercel authentication on this computer
- Confirmation that `cellzy.ca` should replace the current production site
